# Неочевидная информация по работе биржи и технических процессов
Здесь мы собрали информацию, которая не всегда является очевидной, но может быть полезна при принятии решений и торговле.

---
## Формат даты и времени
Все поля с типом dateTime передаются в формате UTC (Coordinated Universal Time).

Рекомендуется:
- интерпретировать все временные значения как UTC.
- выполнять преобразование в локальное время на стороне клиента при необходимости.
