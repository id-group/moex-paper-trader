# Условия внебиржевых сделок

Это сделки с ценными бумагами, которые учитывается на неторговом разделе счета депо. Сделки заключаются вне биржевых торгов на особых условиях.

Ознакоьметсь с условиями внебиржевых сделок:
- Пока действует ограничение, бумагу нельзя продать на биржевых торгах
- Исполнение заявок не гарантировано и зависит от спроса и предложения
- Расчеты по сделке пройдут в рублях. Стоимость купленных бумаг в Портфеле будет отображаться в рублях
- Отменить заявку можно через API или в разделе «Портфель» — Заявки — Биржевые заявки в мобильном приложении "БКС Мир инвестиций"
- Заявки действуют в течение одного дня. Неисполненные заявки отменяются в конце торгового дня. Для СПБ - поручение (заявка) на заключение сделки с Заблокированными на СПБ Бирже ценными бумагами направляется на условиях «действительно до 19 часов 00 минут по московскому времени текущего рабочего дня
- Заявки могут исполняться частями. Частично выполненная заявка остается активной до конца торгового дня, затем отменяется
- Сделки по бумагам, которые хранятся на основном счете депозитария Санкт-Петербургской Биржи, совершаются только между клиентами БКС Мир Инвестиций (ООО "Компания БКС").
- Сделки по бумагам, которые хранятся в Национальном расчетном депозитарии (тикер заканчивается на «-RM»), совершаются между участниками внебиржевых торгов ПАО Московская биржа.
- Текущая цена в рублях бумаги, которая хранится на основном счете депозитария Санкт-Петербургской Биржи, — это цена последней сделки между клиентами БКС Мир Инвестиций. [Подробнее про торговлю вне биржи (БКС) - класс QMEBLCK](/otc/bcs)
- Текущая цена в рублях бумаги, которая хранится в Национальном расчетном депозитарии (НРД), — это текущая цена на внебиржевых торгах ПАО Московская биржа. [Подробнее про торговлю вне биржи (Мосбиржа) - класс MTQR](/otc/moex)
