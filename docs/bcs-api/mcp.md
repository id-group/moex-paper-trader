# MCP сервер

Model Context Protocol (MCP) — стандарт, с помощью которого ИИ-приложение (Claude, ChatGPT, Cursor и другие) обращается к внешним данным и функциям. MCP-сервер БКС даёт ИИ-ассистенту доступ к вашему счёту через Trade API: вы задаёте вопрос обычными словами — «Покажи мой портфель», «Какие лимиты доступны?» — а ассистент сам вызывает нужные методы API.

Опыт программирования не нужен. Подключение занимает около 15 минут.

## Как это работает

- Пользователь подключает MCP-коннектор в ИИ-клиенте и указывает refresh-токен в настройках подключения.
- Пользователь формулирует запрос в диалоге на естественном языке.
- MCP-сервер и ИИ-клиент определяют, какие действия нужны для выполнения запроса.
- Результат выполнения отображается пользователю в диалоге.

Refresh-токен вводится один раз при настройке подключения и не должен передаваться в тексте переписки. Набор доступных действий определяется правами этого токена.

## Возможности

MCP-сервер предоставляет доступ к возможностям публичного Trade API.

### Аналитика и мониторинг

- получение рыночной информации и данных об инструментах;
- просмотр котировок, стакана, свечей и последних сделок;
- проверка состояния торгов и расписания торговых сессий.

### Управление портфелем

- просмотр портфеля, позиций, остатков и доступных лимитов;
- получение информации о маржинальных показателях и обеспечении.

### Торговые операции

- просмотр текущих заявок и их статусов;
- создание, изменение и отмена заявок при наличии соответствующих прав.

### Анализ операций

- просмотр истории сделок и неторговых операций.

Доступные действия зависят от прав refresh-токена. Операции, которые изменяют состояние счёта или создают торговые поручения, требуют торгового токена и явного подтверждения пользователя.

## Как подключить за 4 шага

1. [Выпустите токен](#шаг-1-выпустите-токен) в веб-версии БКС Мир инвестиций.
2. [Подключите MCP-сервер](#шаг-2-подключите-mcp-сервер) в своём ИИ-клиенте по инструкции на нужной вкладке.
3. [Проверьте подключение](#шаг-3-проверьте-подключение) запросом «Покажи мой портфель БКС».
4. [Начните работу со стартового промпта](#шаг-4-начните-со-стартового-промпта), чтобы ассистент брал данные только из БКС.

Если что-то не получается — на каждой вкладке есть **промпт-помощник**: скопируйте его в чат с ИИ, и ассистент проведёт вас по шагам и поможет разобрать ошибку. Ответы на частые вопросы — в разделе [FAQ](#faq).

## Шаг 1. Выпустите токен

**1.** [Откройте веб-версию БКС Мир инвестиций](https://lk.bcs.ru/profile/account): **Профиль** → **Счета и тарифы** → выберите счёт. В разделе **О счете** нажмите **Токены API**.

**2.** Нажмите **Выпустить токен**.

**3.** Выберите тип доступа **Только для чтения** и нажмите **Выпустить токен**. Для первого знакомства с MCP этого достаточно: ассистент сможет смотреть портфель, котировки и историю, но не сможет выставлять заявки. Токен для торговли можно выпустить позже.

**4.** Нажмите **Скопировать** и сохраните токен в надёжном месте — он показывается только один раз.

Токен действует 90 дней и привязан к одному счёту. Подробнее о токенах и правах доступа — в разделе [Быстрый старт](/).

### Способ 1. Коннектор в настройках

Этот способ не требует ни редактирования файлов, ни установки Node.js.

**1.** Откройте **Settings** (**Настройки**) → **Connectors** (**Коннекторы**) и нажмите **Add** (**Добавить**) → **Add custom connector** (**Добавить свой коннектор**).

**2.** Укажите название, например `БКС`, и адрес сервера `https://be.broker.ru/trade-api-mcp-server/mcp`, затем нажмите **Continue** (**Продолжить**).

**3.** В блоке **Authentication** выберите **No sign-in** — приложение обычно само отмечает этот вариант меткой **Detected**. В блоке **Request headers** выберите в первом поле заголовок `authorization`, а в поле рядом укажите `Bearer ВАШ_REFRESH_ТОКЕН` — с вашим токеном вместо `ВАШ_REFRESH_ТОКЕН`. Слово `Bearer` и пробел после него обязательны: значение отправляется ровно в том виде, в котором введено. Оставьте включённым флажок **Required** и нажмите **Add** (**Добавить**).

Предупреждение о доступе без входа учитывать не нужно: доступ к вашему счёту даёт только токен в заголовке.

**4.** На странице коннектора нажмите **Connect** (**Подключить**).

**Как понять, что всё ок:** коннектор `БКС` появился в списке, а в новом чате его инструменты видны в меню инструментов под полем ввода.

:::note[Функция доступна не всем пользователям]
Если пункта **Add custom connector** нет в настройках, подключите сервер вторым способом.
:::

### Способ 2. Файл конфигурации

Для связи с удалённым сервером используется утилита `mcp-remote`, поэтому нужен установленный [Node.js](https://nodejs.org/) версии LTS.

**1. Проверьте Node.js.** Откройте терминал (macOS) или PowerShell (Windows) и выполните:

```bash
node --version
```

**Как понять, что всё ок:** команда вывела версию, например `v22.11.0`. Если появилось `command not found` или «не является внутренней или внешней командой» — установите Node.js LTS с [nodejs.org](https://nodejs.org/) и перезапустите терминал.

**2. Откройте файл настроек.** В Claude Desktop выберите **Settings** (**Настройки**) → **Developer** (**Разработчик**) → **Edit Config** (**Изменить конфиг**). Откроется папка с файлом `claude_desktop_config.json` — откройте его в текстовом редакторе.

Где лежит файл:

- macOS: `~/Library/Application Support/Claude/claude_desktop_config.json`
- Windows: `%APPDATA%\Claude\claude_desktop_config.json`

**3. Добавьте блок БКС.** Если файл пустой или в нём только `{}`, замените содержимое целиком:


Если в файле уже есть другие параметры (например, `preferences`) или другие MCP-серверы, не заменяйте файл, а добавьте блок рядом с ними:

```json {17}
{
  "preferences": {
    "...": "..."
  },
  "mcpServers": {
    "other-server": {
      "...": "..."
    },
    "bcs-trade-api": {
      "command": "npx",
      "args": [
        "-y", "mcp-remote",
        "https://be.broker.ru/trade-api-mcp-server/mcp",
        "--header",
        "Authorization:Bearer ${BCS_TOKEN}"
      ],
      "env": { "BCS_TOKEN": "ВАШ_REFRESH_ТОКЕН" }
    }
  }
}
```

- Ключ `mcpServers` в файле должен быть только один. Если он уже есть — добавьте `bcs-trade-api` внутрь него.
- После закрывающей скобки `}` каждого блока ставится запятая, если за ним идёт следующий блок. После последнего блока запятая не нужна.
- Замените `ВАШ_REFRESH_ТОКЕН` в параметре `BCS_TOKEN` на свой токен — только сам токен, без слова `Bearer` и кавычек вокруг него. Строку `Authorization:Bearer ${BCS_TOKEN}` не меняйте: Claude Desktop сам подставит в неё значение `BCS_TOKEN`.

## Шаг 3. Проверьте подключение

Откройте новый чат и напишите:

> Покажи мой портфель БКС

Ассистент должен вызвать инструменты БКС — клиент показывает это отдельной строкой над ответом и может попросить разрешение на вызов — и вывести список бумаг на вашем счёте.

Пока подключение не проверено, не поручайте ассистенту создавать, изменять или отменять заявки. Если что-то пошло не так — загляните в [FAQ](#faq).

## Шаг 4. Начните со стартового промпта

Если у вас подключено несколько MCP-серверов (например, другого брокера или биржевых данных), ассистент может взять данные не из того источника. Чтобы этого не случилось, начинайте работу с промпта, который явно называет сервер БКС:

```text
Работаем с моим счётом в БКС. Используй только инструменты MCP-сервера «bcs-trade-api».
Другие подключённые MCP-серверы не используй, пока я не попрошу.

1. Перечисли доступные инструменты БКС.
2. Покажи мой портфель: бумаги, количество, стоимость, доля.

Правила: не выставляй, не меняй и не отменяй заявки без моего явного подтверждения.
Если данных не хватает — скажи об этом, не додумывай.
```

Если при подключении вы назвали сервер иначе, замените `bcs-trade-api` на своё имя.

Чтобы не вставлять промпт в каждый чат, сохраните его в настройках клиента:

- **Claude Desktop** — создайте проект и вставьте промпт в инструкции проекта, либо добавьте его в **Settings** → **Profile** → персональные предпочтения.
- **Claude Code** — добавьте текст в файл `~/.claude/CLAUDE.md` (для всех проектов) или `CLAUDE.md` в папке проекта.
- **Cursor** — **Settings** → **Cursor Settings** → **Rules** → **User Rules**.
- **VS Code** — файл `.github/copilot-instructions.md` в папке проекта.
- **ChatGPT** — **Settings** → **Personalization** → **Custom instructions** или инструкции проекта.

## FAQ

<details>
<summary>Какой токен выбрать: «Только для чтения» или «Для торговли и чтения данных»?</summary>

Начните с «Только для чтения»: ассистент сможет смотреть портфель, котировки, историю и лимиты, но физически не сможет выставить заявку. Токен для торговли выпускайте, только когда разберётесь, как ассистент работает, и будете готовы проверять каждое поручение перед подтверждением.

</details>

<details>
<summary>Ассистент говорит, что не видит инструментов БКС</summary>

1. Убедитесь, что клиент полностью перезапущен после настройки (для Claude Desktop — через строку меню или трей, а не крестиком).
2. Проверьте статус сервера: в Claude Code — `claude mcp list`, в Cursor и VS Code — в списке MCP-серверов.
3. В Cursor и VS Code переключите чат в режим **Agent**.
4. Если статус ошибочный — скопируйте промпт-помощник со вкладки своего клиента в чат с ИИ и опишите, что видите.

</details>

<details>
<summary>Ошибка 401 или Unauthorized</summary>

Сервер не принял токен. Частые причины:

- истёк срок действия — токен живёт 90 дней;
- токен удалён в веб-версии БКС Мир инвестиций;
- при копировании потерялся символ, добавился пробел или пропало слово `Bearer`.

Выпустите новый токен и замените его в настройках клиента.

</details>

<details>
<summary>Я случайно отправил токен в чат с ИИ. Что делать?</summary>

Сразу удалите этот токен в веб-версии БКС Мир инвестиций (**Профиль** → **Счета и тарифы** → счёт → **Токены API** → значок удаления) и выпустите новый. Удалить сообщение из переписки недостаточно: текст мог уже сохраниться на стороне ИИ-сервиса.

</details>

<details>
<summary>Ассистент взял данные из другого MCP-сервера</summary>

Начните новый чат со [стартового промпта](#шаг-4-начните-со-стартового-промпта) и сохраните его в инструкциях клиента. Если проблема повторяется — временно отключите другие MCP-серверы в настройках клиента.

</details>

<details>
<summary>Ассистент хочет выставить заявку без моего подтверждения</summary>

Большинство клиентов перед вызовом каждого инструмента спрашивают разрешение — не включайте для инструментов БКС автоматическое одобрение. Для полной гарантии используйте токен «Только для чтения». Перед подтверждением торговой операции проверяйте инструмент, направление, количество, цену и срок действия заявки.

</details>

<details>
<summary>Токен истекает через 90 дней. Как не потерять доступ?</summary>

За 10 дней до окончания срока действия токена мы пришлём вам напоминание. Получив его, выпустите новый токен и замените его в настройках клиента: в файле конфигурации или повторным добавлением сервера (Claude Code — `claude mcp remove bcs-trade-api -s user`, затем шаг 3).

</details>

<details>
<summary>Можно ли подключить MCP в браузерной версии Claude.ai или ChatGPT?</summary>

Пока нет: подключение в веб-версиях временно недоступно. Используйте Claude Desktop, Claude Code, Cursor, VS Code, ChatGPT Desktop или Qwen Code.

</details>

<details>
<summary>Ассистент отвечает «слишком много запросов» или работает медленно</summary>

На MCP-сервер действуют те же частотные ограничения, что и на Trade API — см. раздел [Ограничения](/restrictions). Попросите ассистента запрашивать данные реже или по меньшему числу инструментов за раз.

</details>

<details>
<summary>Ничего не помогло. Куда обратиться?</summary>

Напишите на [tradeapi@bcs.ru](mailto:tradeapi@bcs.ru) и укажите: ИИ-клиент и его версию, операционную систему, текст ошибки и скриншот. **Токен в письмо не добавляйте** и замажьте его на скриншотах.

</details>

## Ответственность и безопасность

MCP и подключённый ИИ-агент являются техническими инструментами для взаимодействия с Trade API. ИИ может неправильно понять запрос, ошибиться при интерпретации рыночных данных или предложить неподходящее действие.

БКС не несёт ответственности за:

- корректность, полноту и целесообразность решений, которые принимает ИИ-агент;
- убытки и другие последствия действий или бездействия ИИ-агента;
- ошибки, сбои и ограничения стороннего ИИ-клиента;
- последствия неправильной настройки MCP-подключения;
- несанкционированные операции при компрометации refresh-токена или доступа к ИИ-клиенту.

Пользователь самостоятельно отвечает за выпуск и хранение токена, настройку MCP-клиента, проверку ответов ИИ и все операции, выполненные в его авторизованной сессии. Перед подтверждением торговой операции необходимо проверить инструмент, направление, количество, цену и срок действия заявки.

Для задач только на чтение используйте токен без торговых прав. Учитывайте частотные и сетевые ограничения API из раздела [Ограничения](/restrictions). MCP-сервер не является инвестиционной рекомендацией.

Подробнее о рисках использования MCP и ИИ-агентов — в документе [«Риски использования MCP и ИИ-агентов»](https://cdn.bcs.ru/static/bcs/files/riski-mcp-ii-agenty.pdf).
