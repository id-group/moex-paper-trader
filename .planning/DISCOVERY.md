## 4. Открытые вопросы владельцу

1. **Память агента.** Варианты: (а) OpenCode Go через `openai-compatible`: ключ из вашего OpenCode Go в `~/.claude-mem/.env`, модель `deepseek-v4.1-flash`; (б) локальный Ollama (нужно поставить и скачать модель); (в) подписка Anthropic (нужен Claude Code с логином). Рекомендация: (а) — провайдер и так получает код проекта из ваших сессий, новых получателей данных не появляется.
2. **Авто-редакция секретов в claude-mem** (`CLAUDE_MEM_REDACT_ENABLED=true`). Рекомендация: включить.
3. **Хранение refresh-токенов БКС:** только переменные окружения (рекомендация) или локальный файл вне git.
4. **Скоуп этапа 2:** подтвердить список из ARCHITECTURE §5; вынести `orders/edit` и `last-trades` за пределы MVP.
5. **Коммит GSD-файлов:** решено владельцем — коммитить вендорную копию, кроме `.opencode/opencode.json`. Установка с `--relative-includes`, абсолютных путей в коммите нет.

## 5. Что не сделано и почему

- Интерактивные `gsd-new-project` и `gsd-ingest-docs` требуют диалога с владельцем; их роль выполнена вручную по шаблонам GSD на основе разобранных документов.
- Память: установка claude-mem 15.7.0 с `--provider host` завершилась ошибкой — режим требует уже запущенного наблюдателя на 127.0.0.1:37777/37778. Установку откатили: плагин OpenCode удалён, глобальный `opencode.json` возвращён к исходному виду, запись в пользовательском PATH удалена. Папка данных `~/.claude-mem` сохранена установщиком; Bun и uv, которые установщик поставил, оставлены.
- Коммиты и `git push` не выполнялись (`AGENTS.md` §6).
