# Модель исполнения — спецификация

**Не упрощать без согласия владельца** (инвариант — принцип №6 AGENTS.md).

## Маркет-ордера

1. Немедленный кросс стакана: buy — по ask, sell — по bid.
2. Проскальзывание — всегда в неблагоприятную сторону:
   - базовый случайный компонент 0.05–0.15%;
   - плюс тир от размера ордера относительно ADV:
     <1% → +0.05%, 1–5% → +0.1%, >5% → +0.2%.
3. Seed генератора — из `Clock`/конфига (детерминизм в REPLAY).

## Контроль ликвидности

- Порог: дефолт 5% ADV, настраивается на профиль брокера.
- Превышение → reject с кодом ошибки контракта БКС (согласовать:
  RESOURCE_EXHAUSTED/CONFLICT — enum `ErrorResponse` в `docs/bcs-api/http/portfolio.md`)
  ИЛИ разбивка на части — политика настраивается: REJECT | SPLIT.

## Лимитные ордера

- Постановка в очередь; исполнение при пересечении рынка:
  buy: ask ≤ limit, цена = min(limit, bestAsk); sell — симметрично.
- Частичные исполнения по прошедшему объёму.

## Жизненный цикл

- NEW → PARTIALLY_FILLED → FILLED / CANCELLED / REJECTED; лог переходов в `order_events`.
- Cancel/edit — через порт (edit = cancel + create, как у БКС).

## Комиссии

- Применяются к каждому fill через `CommissionCalculator` (`core/commission`);
  тарифы — см. принцип №7 AGENTS.md и skill `bcs-portfolio`.
