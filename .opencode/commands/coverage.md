Проверь покрытие тестами и покажи, где порог 80% не выполнен. Фильтр по пакету: `$ARGUMENTS`
(если пусто — весь проект).

Перед gradlew-командами выстави JDK 25: `$env:JAVA_HOME='C:\Users\id-gr\.jdks\liberica-full-25.0.4'`

1. Запусти `./gradlew test jacocoTestCoverageVerification`. Отчёт формируется в
   `build/reports/jacoco/test/jacocoTestReport.xml` (XML) и `build/reports/jacoco/test/html/index.html`.
2. Если проверка зелёная — выведи общее покрытие строк и инструкций по bundle и заверши.
3. Если красная — прочитай XML и выведи таблицу классов с покрытием инструкций ниже 80%
   (колонки: класс / пакет / покрыто, % / непокрытые строки). Учитывай только пакет из `$ARGUMENTS`,
   если он задан.
4. Для каждого класса ниже порога кратко назови непокрытые ветки и поведение, для которого
   нужен тест. Не пиши продакшн-код в этой команде: сначала тесты (`/tdd`).

Порог 80% задан в `build.gradle` (`jacocoTestCoverageVerification`). Не снижай его без
разрешения владельца.
