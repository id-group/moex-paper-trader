---

Дай краткий статус проекта, не больше 15 строк. Номер этапа (необязательно): $ARGUMENTS

1. Определи текущий этап по `docs/plan.md` и `docs/progress.md`; сверь DoD с брифом `docs/agent-briefs/stage-N-*.md`.
2. Перечисли невыполненные пункты из раздела «Сейчас» в `docs/plan.md`.
3. Выполни `git status --short`: сколько файлов изменено и есть ли среди них `.env*`, `*.key`, `*.pem` (их быть не должно).
4. Назови одно следующее действие, которое можно выполнить без подтверждения владельца.

Из команд используй только `git`. Ничего не меняй.
