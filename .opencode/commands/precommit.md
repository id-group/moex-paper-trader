Выполни предкоммит-проверку строго по шагам, не пропуская ни одного. Gradle-проверки делегируй одному субагенту `precommit-checker` (модель `opencode-go/qwen3.8-flash`); он возвращает только краткий отчёт, не полный лог. Не запускай проверки параллельно и не проси субагента исправлять файлы.

Перед запуском проверь `MOEX_JAVA25_HOME`: если переменная пуста, Gradle не запускать, указать блокировку в отчёте.

1. **Формат, тесты и покрытие**: субагент выставляет JDK 25 и запускает `./gradlew spotlessCheck` и `./gradlew test jacocoTestCoverageVerification` последовательно. При падении `spotlessCheck` основной агент запускает `spotlessApply`, проверяет `git diff` на случайные изменения логики и повторно делегирует проверки. При падении тестов основной агент разбирает конкретные сбои, исправляет их и повторно делегирует. При падении порога покрытия JaCoCo (сейчас 60% временно, `docs/temporary-decisions.md` #9) основной агент запускает `/coverage` и добавляет тесты по непокрытым классам (TDD, см. `/tdd`).
2. **Чистота коммита**: основной агент запускает `git status --short` — покажи весь список; убедись, что нет
   `.env`, `.env.local`, `*.key`, `*.pem` и незапланированных файлов; изменения
   `build.gradle`/`settings.gradle` — только с явного разрешения владельца.
3. **Отчёт**: таблица «проверка / результат / время» + предложенное сообщение коммита
    (ветка `feature/*` или `fix/*`, при новой зависимости — обоснование в сообщении).
4. **Жди явного подтверждения пользователя — не коммить самостоятельно.**
