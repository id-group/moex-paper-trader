Выполни предкоммит-проверку строго по шагам, не пропуская ни одного.

Перед gradlew-командами выстави JDK 25: `$env:JAVA_HOME='C:\Users\id-gr\.jdks\liberica-full-25.0.4'`

1. **Формат**: запусти `./gradlew spotlessCheck`. Если не зелёный — запусти
   `./gradlew spotlessApply`, разбери `git diff` (что поменял форматтер, не затёрта ли
   логика) и повтори check.
2. **Тесты**: запусти `./gradlew test`. Если не зелёный — исправь и повтори.
   Новая бизнес-логика должна быть покрыта тестами (цель ≥ 80%).
3. **Чистота коммита**: `git status --short` — покажи весь список; убедись, что нет
   `.env`, `.env.local`, `*.key`, `*.pem` и незапланированных файлов; изменения
   `build.gradle`/`settings.gradle` — только с явного разрешения владельца.
4. **Отчёт**: таблица «проверка / результат / время» + предложенное сообщение коммита
   (ветка `feature/*` или `fix/*`, при новой зависимости — обоснование в сообщении).
5. **Жди явного подтверждения пользователя — не коммить самостоятельно.**
